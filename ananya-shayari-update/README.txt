HOW TO ADD HER PICTURES:
1. Put your photos inside the images folder, named:
   ananya-1.jpg
   ananya-2.jpg
   ananya-3.jpg
2. In index.html, find the PHOTO PLACEHOLDER comments in the section id="ananya-photos".
3. Replace each placeholder <div class="photo-placeholder">...</div> with the matching image tag. Example:
   <img src="images/ananya-1.jpg" alt="Ananya smiling">
4. Do the same for ananya-2.jpg and ananya-3.jpg.
5. Save all files and refresh the website.

Keep index.html, style.css and script.js in the same folder. The images folder should be beside index.html.
